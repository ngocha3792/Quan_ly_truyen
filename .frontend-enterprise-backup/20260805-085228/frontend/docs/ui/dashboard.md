# Dashboard Quản Lý Truyện

Giao diện được tạo tự động bởi `Create-QuanLyTruyenDashboard.ps1`.

## Thành phần

- Sidebar quản trị responsive.
- Header, tìm kiếm và tài khoản quản trị viên.
- KPI cards.
- Biểu đồ SVG tương tác theo khoảng thời gian.
- Trạng thái hệ thống và hoạt động gần đây.
- Bảng truyện mới cập nhật.
- Danh sách bình luận gần đây.
- Không phụ thuộc thư viện UI hoặc chart bên ngoài.

## Chạy

```powershell
npm start
```

Mở `http://localhost:4200`.
