# Trang chủ người dùng QuanLyTruyen

Trang được tạo bởi `Create-QuanLyTruyenHome-FIXED.ps1`.

## Route

- Trang chủ: `/`
- Dashboard quản trị: `/dashboard` nếu dashboard đã tồn tại trước khi chạy script.

## Thành phần

- Header tối, tìm kiếm, thông báo và tài khoản.
- Hero slider có ba truyện nổi bật.
- Lối tắt nội dung.
- Grid truyện đang hot.
- Top truyện tuần.
- Truyện mới cập nhật.
- Thể loại phổ biến.
- Dark mode và responsive.
- SVG assets nội bộ, không phụ thuộc CDN ảnh.
